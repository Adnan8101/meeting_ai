API Reference

Integrate AI Meeting Agent into your applications with our REST API.

Authentication

Include your API key in the Authorization header:

Authorization: Bearer YOUR_API_KEY

Analyze Transcript

POST /api/analyze

Request Body:

{
  "transcript": "John: Let's discuss the Q1 roadmap...",
  "options": {
    "create_trello_cards": true,
    "create_jira_tickets": false
  }
}

Response:

{
  "summary": "Team discussed Q1 roadmap priorities...",
  "action_items": [
    "John to finalize roadmap by Friday",
    "Sarah to prepare presentation"
  ],
  "topics": ["Q1 Planning", "Product Roadmap"],
  "decisions": [
    "Approved budget for Q1",
    "Selected new design system"
  ]
}

Get Team Members

GET /api/teams/:id/members

Response:

{
  "team_id": "123abc",
  "members": [
    {
      "id": "user1",
      "name": "John Doe",
      "email": "john@example.com",
      "role": "owner"
    }
  ]
}

Frequently Asked Questions

What transcript formats are supported?

We support plain text files and transcripts from Google Meet, Zoom, and Microsoft Teams. You can paste text directly or upload files in TXT, DOC, DOCX, or PDF format.

Is my data secure?

Yes! All data is encrypted in transit and at rest. We use industry-standard security practices and never share your data with third parties.

How accurate is the AI analysis?

Our AI models are trained on millions of meeting transcripts and achieve high accuracy for action item extraction and summarization. However, we always recommend reviewing the output.

Can I use this for free?

Yes! We offer a free tier with limited analyses per month. For unlimited usage and advanced features, check out our premium plans.
